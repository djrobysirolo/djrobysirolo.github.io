# DJ ROBY – DANCE MEMORIES

Sito statico pronto per GitHub Pages.

## Pubblicazione

1. Caricare tutti i file nella cartella principale di un repository GitHub pubblico.
2. Aprire **Settings → Pages**.
3. In **Build and deployment**, scegliere **Deploy from a branch**.
4. Selezionare il branch `main`, cartella `/ (root)`, quindi **Save**.
